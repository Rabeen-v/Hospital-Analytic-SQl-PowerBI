# Hospital Analytics Dashboard

## Project Overview
This project focuses on analyzing hospital data using SQL and Power BI.

## Tools Used
- MySQL
- Power BI
- Power Query

## SQL Analysis
- Patient analysis
- Doctor analysis
- Department analysis
- Admission analysis
- Billing analysis
- Advanced SQL queries

## Power BI Dashboard
The dashboard provides insights into:
- Total Patients
- Total Admissions
- Admissions by Department
- Doctor-wise Admissions
- Diagnosis Distribution
- Revenue/Billing Analysis

## Project Objective
To transform hospital data into meaningful insights using SQL
and present the results through an interactive Power BI dashboard.

## Role
Data Analytics Project – Fresher Portfolio
